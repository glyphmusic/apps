# Glyph 0.4.0

- Transfer music from Spotify, YouTube Music, Deezer, SoundCloud and Last.fm without a login or keys; new playlists can be created from a pasted link or a playlist file.
- Discord Rich Presence, MPD remote playback, spatial audio (Mono, Stereo, Spatial), smart shuffle and opt-in listening statistics.
- A local and a server-relayed MCP server for AI assistants (27 tools).
- Redesigned lyrics view with version choice and timing adjustment; lyrics also found through search.
- Faster YouTube sources (r-dlp by default, native InnerTube search); server downloads retry and fall back to another quality.
- Queue "Up next" section, right-click menus on player controls, full artist discographies, followed artists in the sidebar.
- Settings > Support > Docs opens docs.glyph.my. New languages: Español, Français, Italiano, Polski, Português, Türkçe, Українська.

See CHANGELOG.md for the complete list.
