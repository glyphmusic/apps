# Glyph 0.12.12 - 2026-11-20

- **Notifications on phones (Android)**: Glyph checks in the background for new versions and new releases from artists you follow, with toggles in Settings > Notifications.
- **Shared links play in the browser**: opening a glyph.my link in a browser opens the web player with the list ready to play, save or open in Glyph; sharing from the web player now makes real glyph.my links when signed in.
- **Bass boost with "Even out volume" fixed**: boosting the bass is now clearly audible when volume levelling is on.
- **Album names show at once**: looked-up album names are remembered on the device and load faster.
- **Advanced settings toggle & account storage bar**: power-user settings start hidden behind an "Advanced" switch, and Settings > Account shows how much account storage is used.
- **"Update Glyph" screen**: when a server requires a newer app version, Glyph shows an update prompt instead of broken screens.
- **AI assistants can manage plugins (MCP)**, playlist picture picker on the web (WebP covers), share sheet everywhere on phones, and fewer redundant confirmations.

See CHANGELOG.md for the complete changes.
