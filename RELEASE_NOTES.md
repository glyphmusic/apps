# Glyph 0.11.0 - 2026-11-14

- Songs that would not play start again: YouTube's bot check works with the built-in r-dlp, and when the Glyph server has no YouTube audio this computer finds it itself.
- A song clicked right after the start plays as soon as Glyph is ready instead of doing nothing.
- Home shows your recommendations, popular songs and new releases right away; new releases load several times faster.
- macOS: all text shows again.
- Settings › Playback › Sources is split into Search and YouTube, with clearer texts; YouTube errors appear in your language.
- New switch in Settings › Account: "Glyph links when sharing".
- Linux no longer needs GTK or WebKit; the official YouTube and SoundCloud player opens in the browser there.

See CHANGELOG.md for the complete changes.
