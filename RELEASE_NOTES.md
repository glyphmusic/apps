# Glyph 0.12.0 - 2026-11-15

- Desktop and Android apps now use the new Tauri 2 + Svelte (`glyph-ui`) interface on top of `glyph-core` and `glyph-audio` (with native background playback on Android, mini player, tray, media keys, Discord Rich Presence, plugins, and `glyph://` links).
- Added the browser web player backend (`glyph.my/web`) with direct provider playback, official YouTube embed, browser-local library/stats, E2E encrypted account sync, and server-relay MCP controls.
- Configurable profile section order (`playlists`, `recent`) and expanded MCP tools for queue editing, radio, sleep timer, recent songs, and cross-device playback.

See CHANGELOG.md for the complete changes.
