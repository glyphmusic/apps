# Glyph 0.12.13 - 2026-11-20

- **Server dashboard in the app**: server owners and admin accounts get a **Server** page in the sidebar to inspect accounts, storage, 30-day charts, bans, limits, cache and pinned app versions.
- **Cleaner sound quality**: windowed-sinc sample-rate conversion for natively decoded songs keeps highs clear when song and output sample rates differ, and equalizer headroom now tracks the full filter curve to prevent limiter pumping on bass boosts.
- **Update channel improvements**: switching from Latest back to Stable offers the newest stable build, and apps follow server-pinned Stable/Latest versions when configured.

See CHANGELOG.md for the complete changes.
